# About Me

AWS DevOps & Cloud Infrastructure Engineer building production-grade, secure, and scalable cloud systems from real-world requirements.

My work focuses on turning infrastructure challenges into automated, observable, and resilient systems through Infrastructure as Code, CI/CD pipelines, GitOps workflows, container orchestration, and cloud-native architecture on AWS.

On this GitHub, you'll find projects across static website delivery with CloudFront OAC, serverless contact APIs, containerised applications, Kubernetes orchestration on EKS, secrets rotation, event-driven data pipelines, full observability stacks, blue-green and canary deployments, chaos engineering, multi-region active-active architectures, platform engineering modules, and FinOps cost optimisation.

I work across the full lifecycle of cloud systems: architecture design, infrastructure provisioning, security hardening, CI/CD automation, container orchestration, monitoring and alerting, disaster recovery, and cost governance.

I'm especially interested in platform engineering and DevSecOps — building the internal tooling and guardrails that let product teams ship faster with confidence.
